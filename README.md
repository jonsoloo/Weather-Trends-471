# Weather Trends for Data Visualization

CMSC471 Assignment 1 which is an interactive D3 chart of US weather in 2017, from Jan 1 to Sep 21.

- Drag the slider to pick a day, and use the dropdowns to change X, Y and bubble size
- Hover a dot to see that station's numbers
- Click a region in the legend to highlight it
- Click "Show Hurricane Harvey" to see the rain that hit Houston on Aug 27
- Click any dot to see that station's whole year in the bar chart below

## Run it

Open `index.html` with the Live Server extension in VS Code.

## Data

NOAA daily weather, 2017 (`data/weather.csv`) which was downloaded from course website on Assignment 1
